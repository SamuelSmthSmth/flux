### Question
Determine all functions $f: \mathbb{R} \to \mathbb{R}$ such that for all $x, y \in \mathbb{R}$,

$$ f([x]y) = f(x)[f(y)] $$

where $[x]$ denotes the greatest integer less than or equal to $x$.

### The Solution
Let $P(x,y)$ be the assertion $f([x]y) = f(x)[f(y)]$.

First, if $f(x) = c$ (a constant function), then:
$$ c = c[c] $$
If $c = 0$, this is a valid solution: $f(x) = 0$ is a solution.
If $c \neq 0$, then $[c] = 1 \implies 1 \le c < 2$. Thus any constant function $f(x) = c$ with $c \in [1, 2)$ is a solution.

Now assume $f$ is non-constant.

Let $y = 0$:
$$ f(0) = f(x)[f(0)] $$
If $[f(0)] \neq 0$, then $f(x) = \frac{f(0)}{[f(0)]}$ is a constant, which we assumed is not the case. Hence, $[f(0)] = 0$.
Thus, $f(0) = f(x) \cdot 0 = 0 \implies f(0) = 0$.

Now, let $x \in [0, 1) \implies [x] = 0$.
$$ P(x, y) \implies f(0) = f(x)[f(y)] \implies 0 = f(x)[f(y)] $$
Since $f$ is non-constant, there exists some $x$ such that $f(x) \neq 0$. Thus, $[f(y)] = 0$ for all $y \in \mathbb{R}$.
Substituting $[f(y)] = 0$ back into the original relation:
$$ f([x]y) = f(x) \cdot 0 = 0 $$
For any $x \ge 1$, we can choose $[x] = 1$. Then:
$$ f(y) = 0 \quad \text{for all } y \in \mathbb{R} $$
This contradicts our assumption that $f$ is non-constant. 

Thus, the only solutions are:
1. $f(x) = 0$
2. $f(x) = c$ where $c \in [1, 2)$

### Discussion
Functional equations involving floor functions are notoriously tricky because they break the continuity and injectivity properties that are normally leveraged. 

The key insight here is testing boundary values ($y=0$ and $x \in [0,1)$) to dramatically constrain the range of the term $[f(y)]$. Once you show that $[f(y)]$ must be identically zero for a non-constant function, the entire equation collapses into a contradiction.
