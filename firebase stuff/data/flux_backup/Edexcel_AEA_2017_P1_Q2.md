### Question 2

**(a)** Show that the equation $$\tan x = \frac{\sqrt{3}}{1 + 4 \cos x}$$ can be written in the form $$\sin 2x = \sin(60^\circ - x)$$ **(4)**

**(b)** Solve, for $0 < x < 180^\circ$ $$\tan x = \frac{\sqrt{3}}{1 + 4 \cos x}$$ **(5)**

### Mark Scheme 2

#### **Part (a)**

**Step 1: Rewrite tan** $$\frac{\sin x}{\cos x} = \frac{\sqrt{3}}{1 + 4 \cos x}$$

- **[M1]** Use of $\tan x = \frac{\sin x}{\cos x}$.
    

**Step 2: Cross-multiply and use double angle identity** $$\sin x (1 + 4 \cos x) = \sqrt{3} \cos x$$ $$\sin x + 4 \sin x \cos x = \sqrt{3} \cos x$$ $$\Rightarrow 2 \sin 2x + \sin x = \sqrt{3} \cos x$$

- **[M1]** Applies $\sin 2x = 2 \sin x \cos x$.
    

**Step 3: Rearrange to sine compound angle** $$2 \sin 2x = \sqrt{3} \cos x - \sin x$$ $$\sin 2x = \frac{\sqrt{3}}{2} \cos x - \frac{1}{2} \sin x$$

- **[M1]** Attempts to form $\sin(A \pm B)$.
    

**Step 4: Final Identity** $$\sin 2x = \sin(60^\circ - x) \quad (*)$$

- **[A1]** Correctly shown without error.
    

#### **Part (b)**

**Step 5: Find principal and secondary roots** From $\sin 2x = \sin(60^\circ - x)$: Case 1: $$2x = 60^\circ - x \Rightarrow 3x = 60^\circ \Rightarrow x = 20^\circ$$

- **[B1]** Finds $x = 20^\circ$.
    

Case 2: $$2x = 180^\circ - (60^\circ - x) \Rightarrow 2x = 120^\circ + x \Rightarrow x = 120^\circ$$

- **[M1, A1]** Attempts second solution method; correct root.
    

Case 3: $$2x = 360^\circ + (60^\circ - x) \Rightarrow 3x = 420^\circ \Rightarrow x = 140^\circ$$

- **[M1, A1]** Attempts third solution method; correct root. (Ignore extras outside the range $0 < x < 180^\circ$).
