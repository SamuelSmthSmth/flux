### Question 1

The function $f$ is given by $$f(x) = \sqrt{x+2} \quad \text{for } x \in \mathbb{R}, x \ge 0$$

**(a)** Find $f^{-1}(x)$ and state the domain of $f^{-1}$. **(2)**

The function $g$ is given by $$g(x) = x^2 - 4x + 5 \quad \text{for } x \in \mathbb{R}, x \ge 0$$

**(b)** Find the range of $g$. **(2)**

**(c)** Solve the equation $fg(x) = x$. **(3)**

### Mark Scheme 1

#### **Part (a)**

**Step 1: Find Inverse** $$f^{-1}(x) = x^2 - 2$$

- **[B1]** Correct inverse function.
    

**Step 2: State Domain** Domain is $x \in \mathbb{R}$, $x \ge \sqrt{2}$

- **[B1]** Correct domain (derived from the range of the original function $f(x) \ge \sqrt{2}$).
    

#### **Part (b)**

**Step 3: Complete the Square / Find Minimum** $$g(x) = (x - 2)^2 + 1$$ (or use differentiation to find minimum at $x = 2$).

- **[M1]** Suitable method to find the minimum.
    

**Step 4: State Range** So range is $g(x) \ge 1$

- **[A1]** Correct range.
    

#### **Part (c)**

**Step 5: Set up composite equation** $fg(x) = x$ implies: $$\sqrt{x^2 - 4x + 7} = x$$ or using $g(x) = f^{-1}(x)$: $$x^2 - 4x + 5 = x^2 - 2$$

- **[M1]** Attempts a suitable equation for $fg(x) = x$.
    

**Step 6: Solve for x** Squaring both sides: $$x^2 - 4x + 7 = x^2$$

- **[A1]** Simplifies the equation to cancel $x^2$.
    

$$4x = 7 \Rightarrow x = \frac{7}{4}$$

- **[A1]** Correct final answer.
