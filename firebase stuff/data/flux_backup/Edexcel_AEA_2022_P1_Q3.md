### Question 3

**(a)** Use the formulae for $\sin(A \pm B)$ and $\cos(A \pm B)$ to prove that $\tan(90^\circ - \theta) \equiv \cot \theta$ **(3)**

**(b)** Solve for $0 < \theta < 360^\circ$ $$2 - \sec^2(\theta + 11^\circ) = 2 \tan(\theta + 11^\circ)\tan(\theta - 34^\circ)$$ Give each answer as an integer in degrees. **(8)** **(+S1)**

### Mark Scheme 3

#### **Part (a)**

**Step 1: Write in terms of sin and cos** $$\tan(90^\circ - \theta) = \frac{\sin(90^\circ - \theta)}{\cos(90^\circ - \theta)}$$

- **[M1]**
    

**Step 2: Apply compound angle formulae** $$= \frac{\sin 90^\circ \cos \theta - \cos 90^\circ \sin \theta}{\cos 90^\circ \cos \theta + \sin 90^\circ \sin \theta}$$

- **[M1]** Applies both formulae (must be right signs).
    

**Step 3: Complete proof** $$= \frac{\cos \theta - 0}{0 + \sin \theta} = \frac{\cos \theta}{\sin \theta} = \cot \theta *$$

- __[A1_]_* Correct completion.
    

#### **Part (b)**

**Step 4: Use identities to rearrange** $$2 - (1 + \tan^2(\theta + 11^\circ)) = 2 \tan(\theta + 11^\circ)\tan(\theta - 34^\circ)$$ $$\Rightarrow \cot(\theta - 34^\circ) = \frac{2 \tan(\theta + 11^\circ)}{2 - (1 + \tan^2(\theta + 11^\circ))}$$

- **[M1]** Applies either $\sec^2 x = 1 + \tan^2 x$ or rearranges to make $\cot(\theta - 34^\circ)$ the subject.
    

**Step 5: Identify Double Angle for Tan** $$\Rightarrow \cot(\theta - 34^\circ) = \frac{2 \tan(\theta + 11^\circ)}{1 - \tan^2(\theta + 11^\circ)} = \tan(2(\theta + 11^\circ))$$

- **[M1]** Identifies $\tan 2t$ formula and replaces.
    

**Step 6: Apply result from (a)** $$\Rightarrow \tan(90^\circ - (\theta - 34^\circ)) = \tan(2\theta + 22^\circ)$$

- **[M1, A1]** Uses result from (a) appropriately; correct equation.
