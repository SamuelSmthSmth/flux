### Question 6

Relative to a fixed origin $O$, the points $A$, $B$ and $C$ have position vectors

$$\overrightarrow{OA} = 10\mathbf{i} + 5\mathbf{j} + 4\mathbf{k} \quad \overrightarrow{OB} = -4\mathbf{i} + 7\mathbf{j} - \mathbf{k} \quad \overrightarrow{OC} = -2\mathbf{i} + 17\mathbf{j} + 10\mathbf{k}$$

**(a)** Show that triangle $ABC$ is isosceles. **(2)**

The circle $S$ lies inside triangle $ABC$ such that each side of the triangle is a tangent to $S$.

The centre, $X$, of $S$ lies on the angle bisector of each vertex of the triangle.

The point $D$ lies on $AC$ such that $|\overrightarrow{AD}| = |\overrightarrow{AB}|$

**(b)** Find the position vector of $D$. **(2)**

**(c)** Find the position vector of the midpoint of $BD$. **(2)**

**(d)** Hence show that the position of $X$ is given by

$$\overrightarrow{OX} = 10\mathbf{i} + 5\mathbf{j} + 4\mathbf{k} + p(-2\mathbf{i} + \mathbf{j})$$

where $p$ is a scalar constant. **(4)**

**(e)** Use the angle bisector of vertex $B$ to find another expression for $\overrightarrow{OX}$ in terms of a scalar constant $q$. **(3)**

**(f)** By equating the $\mathbf{k}$ components of the two expressions for $\overrightarrow{OX}$, determine the value of $q$. **(2)**

**(g)** Find

(i) the position vector of the centre of $S$, **(2)**

(ii) the radius of $S$. **(4)**

**(+S2)**

### Mark Scheme

#### **Part (a)**

**Step 1: Calculate lengths**

$$|\overrightarrow{AB}| = \sqrt{14^2 + 2^2 + 5^2} = \dots$$ and $$|\overrightarrow{BC}| = \sqrt{2^2 + 10^2 + 11^2} = \dots$$

- **[M1]** Attempts at least the lengths or squared lengths of $AB$ and $BC$.
    

**Step 2: Conclusion**

$|\overrightarrow{AB}| = \sqrt{225} = 15$ and $|\overrightarrow{BC}| = \sqrt{225} = 15$

$|\overrightarrow{AB}| = |\overrightarrow{BC}|$ Hence ($ABC$ is) isosceles.

- __[A1_]_* Correct lengths and conclusion. May use squared lengths. Condone sign errors in finding the vectors. Ignore any attempt at $|\overrightarrow{AC}|$.
    

#### **Part (b)**

**Step 3: Position vector method**

$$\overrightarrow{OD} = \overrightarrow{OA} + \frac{5}{6}\overrightarrow{AC} = \dots$$ **or** $$\overrightarrow{OC} - \frac{1}{6}\overrightarrow{CA} = \dots$$

- **[M1]** Correct method to find $D$ (follow through their lengths). May use $$|\lambda(-12\mathbf{i} + 12\mathbf{j} + 6\mathbf{k})| = "15"$$ condone poor squaring.
    

**Step 4: Final vector**

$\overrightarrow{OD} = 15\mathbf{j} + 9\mathbf{k}$

- **[A1]** Correct position vector. ISW after correct position vector throughout the question.
    

#### **Part (c)**

**Step 5: Midpoint method**

Let the midpoint be $M$ then $$\overrightarrow{OM} = 0.5(\overrightarrow{OD} + \overrightarrow{OB})$$

or e.g. $$\overrightarrow{OM} = \overrightarrow{OB} + 0.5(\overrightarrow{OD} - \overrightarrow{OB})$$

- **[M1]** Method for midpoint.
    

**Step 6: Final vector**

$= -2\mathbf{i} + 11\mathbf{j} + 4\mathbf{k}$

- **[A1]** Correct position vector.
    

#### **Part (d)**

**Step 7: Find direction vector**

e.g. $$\overrightarrow{AM} = \overrightarrow{OM} - \overrightarrow{OA} = "-2\mathbf{i} + 11\mathbf{j} + 4\mathbf{k}" - (10\mathbf{i} + 5\mathbf{j} + 4\mathbf{k})$$

or e.g. $$\overrightarrow{AM} = \overrightarrow{AB} + \frac{1}{2}\overrightarrow{BD} = "-14\mathbf{i} + 2\mathbf{j} - 5\mathbf{k}" + ("2\mathbf{i} + 4\mathbf{j} + 5\mathbf{k}"); \Rightarrow \overrightarrow{AM} = -12\mathbf{i} + 6\mathbf{j}$$

- **[M1, A1]** (M1 on EPEN) Attempts $\pm\overrightarrow{AM}$ with their $M$; $\pm\overrightarrow{AM}$ correct.
    

**Step 8: Form line equation**

(Triangle $ABD$ is isosceles, so $X$ lies on the line $AM$, so is given by)

$$\overrightarrow{OX} = \overrightarrow{OA} + m\overrightarrow{AM}$$

- **[M1]** Forms an equation for $\overrightarrow{OX}$ using $\overrightarrow{AM}$ that is not just the given answer (unless there is sufficient justification).
    

**Step 9: Final given expression**

$$\overrightarrow{OX} = 10\mathbf{i} + 5\mathbf{j} + 4\mathbf{k} + m(-12\mathbf{i} + 6\mathbf{j})$$

Letting $p = 6m$ (S+) gives $$\overrightarrow{OX} = 10\mathbf{i} + 5\mathbf{j} + 4\mathbf{k} + p(-2\mathbf{i} + \mathbf{j})*$$

- __[A1_]_* Achieves correct answer including $\overrightarrow{OX} =$ following a correct intermediate equation for $\overrightarrow{OX}$ (may be implied if they show clearly $$\overrightarrow{OX} = \overrightarrow{OA} + m\overrightarrow{AM}$$ and deal with the change in the direction vector), not just the answer given. (S+ for good explanation of $p$).
    

#### **Part (e)**

**Step 10: Direction vector for bisector**

Midpoint $AC$ is $N$ $4\mathbf{i} + 11\mathbf{j} + 7\mathbf{k}$

**or** direction of angle bisector at $B$ is $$(\overrightarrow{BN} =) \frac{1}{2}(\overrightarrow{BA} + \overrightarrow{BC}) = 8\mathbf{i} + 4\mathbf{j} + 8\mathbf{k}$$

- **[B1]** Correct midpoint of $AC$ **or** direction vector for bisector.
    

**Step 11: Form second vector equation**

(Since point $X$ is on angle bisector $ABC$ it satisfies) $$\overrightarrow{OX} = -4\mathbf{i} + 7\mathbf{j} - \mathbf{k} + q(8\mathbf{i} + 4\mathbf{j} + 8\mathbf{k})$$

or e.g. $$\overrightarrow{OX} = -4\mathbf{i} + 7\mathbf{j} - \mathbf{k} + q(2\mathbf{i} + \mathbf{j} + 2\mathbf{k})$$

or $$\overrightarrow{OX} = 4\mathbf{i} + 11\mathbf{j} + 7\mathbf{k} + q(2\mathbf{i} + \mathbf{j} + 2\mathbf{k})$$

- **[M1, A1]** Forms a second vector equation in terms of $q$ using a direction vector found using a correct method; Correct equation including $\overrightarrow{OX} =$ (only penalise absence of $\overrightarrow{OX}$ once).
    

#### **Part (f)**

**Step 12: Equate components and solve**

Comparing $\mathbf{k}$ components gives

$4 = -1 + 8q$ so $q = \frac{5}{8}$

(or e.g. $4 = -1 + 2q$ so $q = \frac{5}{2}$)

- **[M1, A1]** Sets the $\mathbf{k}$ component from their $\overrightarrow{OX}$ from (e) equal to $4$ and solves for $q$; For the A1, follow through for their second equation provided the direction vector is a scalar multiple of $2\mathbf{i} + \mathbf{j} + 2\mathbf{k}$ (they may have e.g. $q = \frac{5}{2}$ or e.g. $q = -\frac{3}{2}$ if using $N$).
    

#### **Part (g)(i)**

**Step 13: Substitute $q$**

So, position vector for centre is $$\overrightarrow{OX} = -4\mathbf{i} + 7\mathbf{j} - \mathbf{k} + \frac{5}{8}(8\mathbf{i} + 4\mathbf{j} + 8\mathbf{k})$$

- **[M1]** Attempts the coordinates using their $q$ in their $\overrightarrow{OX}$. (May find using $p = \frac{9}{2}$ and the given $\overrightarrow{OX}$ in part (d)).
    

**Step 14: Final centre vector**

$$= \mathbf{i} + \frac{19}{2}\mathbf{j} + 4\mathbf{k}$$

- **[A1]** Correct centre.
    

#### **Part (g)(ii)**

**Step 15: Identify strategy for radius**

e.g. Midpoint, $N$, $AC$ on circle so need $\overrightarrow{XN}$ ...

_Alt:_ $N$ is midpoint of $AC$, then $AN = 9$ and $|\overrightarrow{AX}| = \dots$ (or $|\overrightarrow{CX}| = \dots$)

- **[M1]** Strategy that can be used to solve the problem – e.g. Identifies or implies a correct point on the circle and uses it in an attempt to find the radius, or uses a right triangle with one side length deduced. There are alternatives.
    

**Step 16: Required vectors or lengths**

$$\overrightarrow{XN} = (4\mathbf{i} + 11\mathbf{j} + 7\mathbf{k}) - (\mathbf{i} + \frac{19}{2}\mathbf{j} + 4\mathbf{k}) = 3\mathbf{i} + \frac{3}{2}\mathbf{j} + 3\mathbf{k}$$

**or** $AN = 9$ and $$|\overrightarrow{AX}| = \sqrt{81 + \frac{81}{4} + 0} = \frac{9\sqrt{5}}{2}$$

- **[A1]** Correct vector for radius or correct lengths of both required sides (or the squares of the side lengths).
    

**Step 17: Calculate magnitude/radius**

$$|\overrightarrow{XN}| = \sqrt{9 + \frac{9}{4} + 9} = \dots$$

**or** $$r^2 = AX^2 - AN^2 = \frac{5}{4} \times 81 - 81 = \dots$$

- **[dM1]** Completes the method. Dependent on the previous method mark.
    

**Step 18: Final answer**

$(r = ) \frac{9}{2}$

- **[A1]** Correct answer.
