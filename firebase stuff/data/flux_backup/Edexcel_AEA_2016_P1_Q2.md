### **Question 2**

Find the exact value of $$\arccos\left(\frac{1}{\sqrt{2}}\right) + \arcsin\left(\frac{1}{3}\right) + 2\arctan\left(\frac{1}{\sqrt{2}}\right)$$ Give your answer as a multiple of $\pi$. _( $\arccos x$ is an alternative notation for $\cos^{-1} x$ etc. )_ **(Total 7 marks)**

### **Mark Scheme 2**

**Step 1: Evaluate the arccos term** $$\arccos\left(\frac{1}{\sqrt{2}}\right) = \frac{\pi}{4}$$

- **[B1]** Correct evaluation.
    

**Step 2: Set up variables for the other terms** Let $$\alpha = \arcsin\left(\frac{1}{3}\right) \Rightarrow \sin \alpha = \frac{1}{3}$$.

- **[B1]** Writes $\sin \alpha = \dots$ (or equivalent triangle with angle $\alpha$ indicated).
    

Let $$\beta = 2\arctan\left(\frac{1}{\sqrt{2}}\right) \Rightarrow \tan\left(\frac{\beta}{2}\right) = \frac{1}{\sqrt{2}}.$$

- **[M1]** Relevant use of $\tan(\beta/2)$ or setting up a relationship using the double angle.
    

**Step 3: Connect alpha and beta using trigonometric identities** Use the double angle formula for cosine in terms of tangent: $$\cos \beta = \frac{1 - \tan^2(\beta/2)}{1 + \tan^2(\beta/2)}$$

- **[M1]** Attempt to use $\tan(2A)$ formula or get a trigonometric ratio for $\beta$.
    

Substitute the value: $$\cos \beta = \frac{1 - (1/\sqrt{2})^2}{1 + (1/\sqrt{2})^2} = \frac{1 - 1/2}{1 + 1/2} = \frac{1/2}{3/2} = \frac{1}{3}$$

- **[A1]** Correct value for $\cos \beta$ derived.
    

_(Alternative: Use $\tan \beta = \frac{2(1/\sqrt{2})}{1 - (1/\sqrt{2})^2} = 2\sqrt{2}$, then deduce $\cos \beta = 1/3$ using a right-angled triangle)._

**Step 4: Deduce relationship between the angles** Since $\sin \alpha = 1/3$ and $\cos \beta = 1/3$ (where $\alpha$ and $\beta$ are acute angles based on their domains), we have: $\sin \alpha = \cos \beta \Rightarrow \alpha + \beta = \frac{\pi}{2}$

- **[M1]** Uses a triangle or some other valid link to conclude the sum is $\pi/2$.
    

**Step 5: Final sum** The total sum is: $$\frac{\pi}{4} + \frac{\pi}{2} = \frac{3\pi}{4}$$

- **[A1]** Correct final answer.
