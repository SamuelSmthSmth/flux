### Question 13

The value of a car, $\text{£}V$, where $V$ is measured in thousands, is modelled by the equation

### Mark Scheme 13

**Step 1: Substitute initial conditions to find $A$**
When $t = 0$, $V = 23$:
$$23 = A + 12\text{e}^0 + 9\text{e}^0 = A + 12 + 9 = A + 21 \Rightarrow A = 2$$
- **[M1]** Substitutes $t = 0$ and $V = 23$ into model to solve for $A$.

**Step 2: State complete equation**

**Step 3: Set up quadratic equation in $\text{e}^{-0.1T}$**

### Question 14

Show, using algebra, that for values of $n \in \mathbb{N}$ where $n$ is not a multiple of 3
$$n^2 + 2 \text{ is always a multiple of 3}$$ **(4)**

### Mark Scheme 14

**Step 1: Set up expressions for integers not divisible by 3**
Any integer $n$ not divisible by 3 can be written as $n = 3k + 1$ or $n = 3k + 2$ for $k \in \mathbb{Z}_{\ge 0}$.
- **[M1]** States that $n$ can be expressed as $3k + 1$ or $3k + 2$ (or $3k \pm 1$).

**Step 2: Prove Case 1 ($n = 3k + 1$)**
$$n^2 + 2 = (3k + 1)^2 + 2 = 9k^2 + 6k + 1 + 2 = 9k^2 + 6k + 3 = 3(3k^2 + 2k + 1)$$
Since $3k^2 + 2k + 1$ is an integer, $n^2 + 2$ is a multiple of 3.
- **[A1]** Correctly expands and factorises for $n = 3k + 1$.

**Step 3: Prove Case 2 ($n = 3k + 2$)**
$$n^2 + 2 = (3k + 2)^2 + 2 = 9k^2 + 12k + 4 + 2 = 9k^2 + 12k + 6 = 3(3k^2 + 4k + 2)$$
Since $3k^2 + 4k + 2$ is an integer, $n^2 + 2$ is a multiple of 3.
- **[A1]** Correctly expands and factorises for $n = 3k + 2$ (or $n = 3k - 1$).

**Step 4: Conclude proof**
Both cases result in a multiple of 3, so $n^2 + 2$ is always a multiple of 3 for all $n \in \mathbb{N}$ not divisible by 3.
- **[A1]** Complete argument with logical conclusion covering all non-multiples of 3.
