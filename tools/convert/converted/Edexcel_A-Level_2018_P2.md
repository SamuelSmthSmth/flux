### **Question 1**

$$\text{g}(x) = \frac{2x + 5}{x - 3} \quad x \ge 5$$

**(a)** Find $\text{gg}(5)$. **(2)**

**(b)** State the range of $\text{g}$. **(1)**

**(c)** Find $\text{g}^{-1}(x)$, stating its domain. **(3)**

### **Mark Scheme 1**

#### **Part (a)**
**Step 1: Calculate $\text{g}(5)$**
$$\text{g}(5) = \frac{2(5) + 5}{5 - 3} = \frac{15}{2} = 7.5$$

**Step 2: Calculate $\text{g}\left(\frac{15}{2}\right)$**
$$\text{gg}(5) = \text{g}\left(\frac{15}{2}\right) = \frac{2\left(\frac{15}{2}\right) + 5}{\frac{15}{2} - 3} = \frac{20}{\frac{9}{2}} = \frac{40}{9}$$

- **[M1]** Attempts $\text{g}(5)$ and substitutes their value into $\text{g}(x)$.
- **[A1]** $\frac{40}{9}$ or $4\frac{4}{9}$ or exact equivalent fraction.

#### **Part (b)**
**Step 3: State the range of $\text{g}$**
$$2 < \text{g}(x) \le \frac{15}{2}$$

- **[B1]** Correct range using appropriate notation, e.g. $2 < \text{g}(x) \le 7.5$, $y \in (2, 7.5]$.

#### **Part (c)**
**Step 4: Rearrange to find the inverse function**
$$y = \frac{2x + 5}{x - 3} \Rightarrow y(x - 3) = 2x + 5 \Rightarrow x(y - 2) = 3y + 5 \Rightarrow x = \frac{3y + 5}{y - 2}$$

$$\text{g}^{-1}(x) = \frac{3x + 5}{x - 2}$$

- **[M1]** Attempt to change the subject of $y = \frac{2x + 5}{x - 3}$ to $x$.
- **[A1]** $\text{g}^{-1}(x) = \frac{3x + 5}{x - 2}$ or $\frac{-3x - 5}{2 - x}$.

**Step 5: State the domain of $\text{g}^{-1}$**

- **[B1]** Correct domain matching the range of $\text{g}$.

### **Question 2**

Relative to a fixed origin $O$,

the point $A$ has position vector $(2\mathbf{i} + 3\mathbf{j} - 4\mathbf{k})$,

the point $B$ has position vector $(4\mathbf{i} - 2\mathbf{j} + 3\mathbf{k})$,

and the point $C$ has position vector $(a\mathbf{i} + 5\mathbf{j} - 2\mathbf{k})$, where $a$ is a constant and $a < 0$

$D$ is the point such that $\vec{AB} = \vec{BD}$.

**(a)** Find the position vector of $D$. **(2)**

Given $|\vec{AC}| = 4$

**(b)** find the value of $a$. **(3)**

### **Mark Scheme 2**

#### **Part (a)**
**Step 1: Calculate the position vector of $D$**
$$\vec{AB} = \mathbf{b} - \mathbf{a} = (4\mathbf{i} - 2\mathbf{j} + 3\mathbf{k}) - (2\mathbf{i} + 3\mathbf{j} - 4\mathbf{k}) = 2\mathbf{i} - 5\mathbf{j} + 7\mathbf{k}$$

$$\vec{OD} = \mathbf{b} + \vec{BD} = \mathbf{b} + \vec{AB} = (4\mathbf{i} - 2\mathbf{j} + 3\mathbf{k}) + (2\mathbf{i} - 5\mathbf{j} + 7\mathbf{k}) = 6\mathbf{i} - 7\mathbf{j} + 10\mathbf{k}$$

- **[M1]** Correct strategy to find $\vec{OD}$, e.g. $\mathbf{b} + (\mathbf{b} - \mathbf{a})$ or $2\mathbf{b} - \mathbf{a}$.
- **[A1]** $6\mathbf{i} - 7\mathbf{j} + 10\mathbf{k}$ or $\begin{pmatrix} 6 \\ -7 \\ 10 \end{pmatrix}$.

#### **Part (b)**
**Step 2: Find the vector $\vec{AC}$**
$$\vec{AC} = \mathbf{c} - \mathbf{a} = (a\mathbf{i} + 5\mathbf{j} - 2\mathbf{k}) - (2\mathbf{i} + 3\mathbf{j} - 4\mathbf{k}) = (a - 2)\mathbf{i} + 2\mathbf{j} + 2\mathbf{k}$$

- **[M1]** Attempts $\vec{AC} = (a - 2)\mathbf{i} + 2\mathbf{j} + 2\mathbf{k}$ and sets $|\vec{AC}| = 4$ or $|\vec{AC}|^2 = 16$.

**Step 3: Solve for $a$**
$$|\vec{AC}|^2 = (a - 2)^2 + 2^2 + 2^2 = 16$$

$$(a - 2)^2 + 8 = 16 \Rightarrow (a - 2)^2 = 8 \Rightarrow a - 2 = \pm\sqrt{8} = \pm 2\sqrt{2}$$

- **[M1]** Solves $(a - 2)^2 + 8 = 16$ to find possible values for $a$.

$$a = 2 - 2\sqrt{2}$$

- **[A1]** $a = 2 - 2\sqrt{2}$ or $2 - \sqrt{8}$ (rejecting $2 + 2\sqrt{2}$ as $a < 0$).

#### **Part (b)**
**Step 3: Sketch the graph**

### **Question 5**

The equation $2x^3 + x^2 - 1 = 0$ has exactly one real root.

**(a)** Show that, for this equation, the Newton-Raphson formula can be written

$$x_{n+1} = \frac{4x_n^3 + x_n^2 + 1}{6x_n^2 + 2x_n}$$ **(3)**

Using the formula given in part (a) with $x_1 = 1$

**(b)** find the values of $x_2$ and $x_3$ **(2)**

**(c)** Explain why, for this question, the Newton-Raphson method cannot be used with $x_1 = 0$ **(1)**

### **Mark Scheme 5**

#### **Part (a)**
**Step 1: Differentiate $\text{f}(x)$**
$$\text{f}(x) = 2x^3 + x^2 - 1 \Rightarrow \text{f}'(x) = 6x^2 + 2x$$

- **[B1]** $\text{f}'(x) = 6x^2 + 2x$

**Step 2: Apply Newton-Raphson formula**
$$x_{n+1} = x_n - \frac{\text{f}(x_n)}{\text{f}'(x_n)} = x_n - \frac{2x_n^3 + x_n^2 - 1}{6x_n^2 + 2x_n}$$

- **[M1]** Correct application of the Newton-Raphson formula.

**Step 3: Simplify algebraic fraction**
$$x_{n+1} = \frac{x_n(6x_n^2 + 2x_n) - (2x_n^3 + x_n^2 - 1)}{6x_n^2 + 2x_n} = \frac{6x_n^3 + 2x_n^2 - 2x_n^3 - x_n^2 + 1}{6x_n^2 + 2x_n} = \frac{4x_n^3 + x_n^2 + 1}{6x_n^2 + 2x_n}$$

- **[A1]** Correct algebraic processing to achieve the given result.

#### **Part (b)**
**Step 4: Compute $x_2$ and $x_3$**
$$x_2 = \frac{4(1)^3 + 1^2 + 1}{6(1)^2 + 2(1)} = \frac{6}{8} = 0.75$$

$$x_3 = \frac{4(0.75)^3 + (0.75)^2 + 1}{6(0.75)^2 + 2(0.75)} = \frac{3.25}{4.875} = \frac{2}{3} \approx 0.667$$

- **[M1]** Attempts to substitute $x_1 = 1$ into formula to find $x_2$.
- **[A1]** $x_2 = 0.75$ and $x_3 = \frac{2}{3}$ or $0.667$ (or better).

#### **Part (c)**
**Step 5: Explain failure at $x_1 = 0$**
When $x_1 = 0$, $\text{f}'(0) = 6(0)^2 + 2(0) = 0$. The Newton-Raphson formula involves division by $\text{f}'(x)$, so division by zero occurs (or the tangent is parallel to the $x$-axis).

- **[B1]** Mentions $\text{f}'(0) = 0$ / division by zero / tangent is parallel to the $x$-axis.

### **Question 6**

$$\text{f}(x) = -3x^3 + 8x^2 - 9x + 10, \quad x \in \mathbb{R}$$

**(a) (i)** Calculate $\text{f}(2)$

**(ii)** Write $\text{f}(x)$ as a product of two algebraic factors. **(3)**

Using the answer to (a)(ii),

**(b)** prove that there are exactly two real solutions to the equation

$$-3y^6 + 8y^4 - 9y^2 + 10 = 0$$ **(2)**

**(c)** deduce the number of real solutions, for $7\pi \le \theta < 10\pi$, to the equation

$$3\tan^3\theta - 8\tan^2\theta + 9\tan\theta - 10 = 0$$ **(1)**

### **Mark Scheme 6**

#### **Part (a)**
**Step 1: Calculate $\text{f}(2)$**
$$\text{f}(2) = -3(2)^3 + 8(2)^2 - 9(2) + 10 = -24 + 32 - 18 + 10 = 0$$

- **[B1]** $\text{f}(2) = 0$ shown.

**Step 2: Factorise $\text{f}(x)$**
Since $\text{f}(2) = 0$, $(x - 2)$ is a factor.

$$\text{f}(x) = (x - 2)(-3x^2 + 2x - 5)$$

- **[M1]** Attempts division or inspection to find the quadratic factor.
- **[A1]** $(x - 2)(-3x^2 + 2x - 5)$ or $(2 - x)(3x^2 - 2x + 5)$.

#### **Part (b)**
**Step 3: Analyze solutions for $y$**
Let $x = y^2$, then $-3y^6 + 8y^4 - 9y^2 + 10 = \text{f}(y^2) = (y^2 - 2)(-3y^4 + 2y^2 - 5) = 0$.

From $y^2 - 2 = 0 \Rightarrow y = \pm\sqrt{2}$ (two real solutions).

For $-3y^4 + 2y^2 - 5 = 0$, let $u = y^2 \Rightarrow -3u^2 + 2u - 5 = 0$.

The discriminant is $b^2 - 4ac = 2^2 - 4(-3)(-5) = 4 - 60 = -56 < 0$.

Since the discriminant is negative, there are no real solutions for $u$, and hence no additional real solutions for $y$.

Thus, there are exactly two real solutions ($y = \sqrt{2}$ and $y = -\sqrt{2}$).

- **[M1]** Sets $y^2 = 2$ and attempts discriminant on the quadratic factor in $y^2$.
- **[A1]** Fully correct proof showing $y = \pm\sqrt{2}$ and discriminant $< 0$ for the other factor.

#### **Part (c)**
**Step 4: Deduce solutions for $\tan\theta$**
$$3\tan^3\theta - 8\tan^2\theta + 9\tan\theta - 10 = 0 \Rightarrow -\text{f}(\tan\theta) = 0 \Rightarrow \text{f}(\tan\theta) = 0$$

From part (a), the only real solution to $\text{f}(x) = 0$ is $x = 2$, so $\tan\theta = 2$.

The interval $7\pi \le \theta < 10\pi$ covers 3 full periods of $\tan\theta$ (each period is $\pi$). $\tan\theta = 2$ has 1 solution per period, so there are 3 real solutions in total.

- **[B1]** 3

$$\frac{-10x + 10}{(x - 3)(1 - 2x)} = \frac{B}{x - 3} + \frac{C}{1 - 2x}$$

$$-10x + 10 = B(1 - 2x) + C(x - 3)$$

Set $x = 3: \quad -20 = B(-5) \Rightarrow B = 4$

#### **Part (b)**

- **[A1]** Complete proof linking LHS to RHS cleanly.

### **Question 13**

**Figure 2** shows a sketch of part of the curve $C$ with equation $y = x\ln x, \quad x > 0$.

Figure 2 shows a sketch of part of the curve $C$ with equation $y = x \ln x, \quad x > 0$
The line $l$ is the normal to $C$ at the point $P(\text{e}, \text{e})$.
The region $R$, shown shaded in Figure 2, is bounded by the curve $C$, the line $l$ and the $x$-axis.

Show that the exact area of $R$ is $A\text{e}^2 + B$ where $A$ and $B$ are rational numbers to be found. **(10)**

### **Mark Scheme 13**

**Step 1: Find gradient of normal line $l$**
$$y = x\ln x \Rightarrow \frac{\text{d}y}{\text{d}x} = 1 \cdot \ln x + x \cdot \frac{1}{x} = \ln x + 1$$

- **[M1]** Uses product rule to differentiate $x\ln x$.
- **[A1]** $\frac{\text{d}y}{\text{d}x} = \ln x + 1$.

At $P(\text{e}, \text{e})$: $\frac{\text{d}y}{\text{d}x} = \ln \text{e} + 1 = 2 \Rightarrow \text{Gradient of normal} = -\frac{1}{2}$.

- **[M1]** Gradient of normal is $-\frac{1}{2}$.

**Step 2: Find $x$-intercept of line $l$**
Equation of $l$: $y - \text{e} = -\frac{1}{2}(x - \text{e})$

Set $y = 0$: $-\text{e} = -\frac{1}{2}(x - \text{e}) \Rightarrow x - \text{e} = 2\text{e} \Rightarrow x = 3\text{e}$

- **[A1]** Line $l$ crosses $x$-axis at $(3\text{e}, 0)$.

**Step 3: Integrate under curve $C$ from $x = 1$ to $x = \text{e}$**
Note: $x\ln x = 0 \Rightarrow x = 1$ (since $x > 0$).

$$\int_1^{\text{e}} x\ln x \text{d}x$$

Use integration by parts: $u = \ln x, \frac{\text{d}v}{\text{d}x} = x \Rightarrow \frac{\text{d}u}{\text{d}x} = \frac{1}{x}, v = \frac{x^2}{2}$

$$\int x\ln x \text{d}x = \frac{x^2}{2}\ln x - \int \frac{x^2}{2} \cdot \frac{1}{x} \text{d}x = \frac{x^2}{2}\ln x - \frac{x^2}{4}$$

- **[M1]** Applies integration by parts to $x\ln x$.
- **[A1]** $\frac{x^2}{2}\ln x - \frac{x^2}{4}$

$$\left[ \frac{x^2}{2}\ln x - \frac{x^2}{4} \right]_1^{\text{e}} = \left( \frac{\text{e}^2}{2} - \frac{\text{e}^2}{4} \right) - \left( 0 - \frac{1}{4} \right) = \frac{\text{e}^2}{4} + \frac{1}{4}$$

- **[M1]** Applies limits $1$ and $\text{e}$.

**Step 4: Find area under normal line $l$ from $x = \text{e}$ to $x = 3\text{e}$**
Triangle with base $3\text{e} - \text{e} = 2\text{e}$ and height $\text{e}$:

$$\text{Area} = \frac{1}{2} \times 2\text{e} \times \text{e} = \text{e}^2$$

- **[M1]** Strategy to calculate total area (area under curve + area under line/triangle).

**Step 5: Total area of region $R$**
$$\text{Total Area} = \left(\frac{\text{e}^2}{4} + \frac{1}{4}\right) + \text{e}^2 = \frac{5}{4}\text{e}^2 + \frac{1}{4}$$

- **[A1]** $A = \frac{5}{4}$ and $B = \frac{1}{4}$ (or $\frac{5}{4}\text{e}^2 + \frac{1}{4}$).

### **Question 14**

A scientist is studying a population of mice on an island.

The number of mice, $N$, in the population, $t$ months after the start of the study, is modelled by the equation

$$N = \frac{900}{3 + 7\text{e}^{-0.25t}}, \quad t \in \mathbb{R}, \quad t \ge 0$$

**(a)** Find the number of mice in the population at the start of the study. **(1)**

**(b)** Show that the rate of growth $\frac{\text{d}N}{\text{d}t}$ is given by

$$\frac{\text{d}N}{\text{d}t} = \frac{N(300 - N)}{1200}$$ **(4)**

The rate of growth is a maximum after $T$ months.

**(c)** Find, according to the model, the value of $T$. **(4)**

According to the model, the maximum number of mice on the island is $P$.

**(d)** State the value of $P$. **(1)**

### **Mark Scheme 14**

#### **Part (a)**
**Step 1: Calculate $N$ at $t = 0$**
$$N = \frac{900}{3 + 7\text{e}^0} = \frac{900}{10} = 90$$

- **[B1]** 90

#### **Part (b)**
**Step 2: Differentiate $N$ with respect to $t$**
$$N = 900(3 + 7\text{e}^{-0.25t})^{-1}$$

$$\frac{\text{d}N}{\text{d}t} = -900(3 + 7\text{e}^{-0.25t})^{-2}(-1.75\text{e}^{-0.25t}) = \frac{1575\text{e}^{-0.25t}}{(3 + 7\text{e}^{-0.25t})^2}$$

- **[M1]** Differentiates $N$ with respect to $t$ using the chain rule or quotient rule.
- **[A1]** $\frac{\text{d}N}{\text{d}t} = \frac{1575\text{e}^{-0.25t}}{(3 + 7\text{e}^{-0.25t})^2}$

**Step 3: Substitute $N$ into expression**
From the original equation:
$$3 + 7\text{e}^{-0.25t} = \frac{900}{N} \Rightarrow 7\text{e}^{-0.25t} = \frac{900 - 3N}{N} = \frac{3(300 - N)}{N}$$

$$\text{e}^{-0.25t} = \frac{3(300 - N)}{7N}$$

- **[M1]** Expresses $\text{e}^{-0.25t}$ or $(3 + 7\text{e}^{-0.25t})$ in terms of $N$.

Substitute back:
$$\frac{\text{d}N}{\text{d}t} = \frac{1575 \cdot \frac{3(300 - N)}{7N}}{\left(\frac{900}{N}\right)^2} = \frac{675 \frac{300 - N}{N}}{\frac{810\,000}{N^2}} = \frac{675 N(300 - N)}{810\,000} = \frac{N(300 - N)}{1200}$$

- **[A1]** Fully correct algebra leading to $\frac{\text{d}N}{\text{d}t} = \frac{N(300 - N)}{1200}$.

#### **Part (c)**
**Step 4: Find $N$ for maximum growth rate**
Growth rate $g(N) = \frac{300N - N^2}{1200}$. The maximum of this quadratic occurs at $N = 150$.

- **[M1]** Recognises rate of growth is maximum when $N = 150$ (or differentiates $\frac{\text{d}N}{\text{d}t}$ wrt $N$ and sets to 0).
- **[A1]** $N = 150$

**Step 5: Solve for $T$**
$$150 = \frac{900}{3 + 7\text{e}^{-0.25T}} \Rightarrow 3 + 7\text{e}^{-0.25T} = 6 \Rightarrow 7\text{e}^{-0.25T} = 3 \Rightarrow \text{e}^{-0.25T} = \frac{3}{7}$$

- **[M1]** Substitutes $N = 150$ into equation for $N$ and solves for $T$.

$$-0.25T = \ln\left(\frac{3}{7}\right) \Rightarrow T = -4\ln\left(\frac{3}{7}\right) = 4\ln\left(\frac{7}{3}\right) \approx 3.39\text{ months}$$

- **[A1]** $T = 4\ln\left(\frac{7}{3}\right) \approx 3.39$ (months).

#### **Part (d)**
**Step 6: State maximum number of mice**
As $t \to \infty, \quad \text{e}^{-0.25t} \to 0 \Rightarrow N \to \frac{900}{3} = 300$

$$P = 300$$

- **[B1]** 300
